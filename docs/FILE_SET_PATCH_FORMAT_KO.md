# 다중 파일 차이 데이터 형식 v1

`psp-file-set-delta-v1` 엔진은 DLC처럼 한 폴더에 있는 여러 독립 파일을 한 번에 패치합니다. 패치 바이너리의 매직은 `P2KODLC1`이며 모든 정수는 리틀 엔디언입니다.

브라우저는 사용자가 선택한 원본 폴더에서 선언된 파일의 크기와 SHA-256을 각각 검증하고, 별도의 새 폴더에 결과 파일을 생성한 뒤 다시 SHA-256을 확인합니다. 원본과 결과 파일은 서버로 전송되지 않습니다.

## 파일 헤더

| 크기 | 형식 | 값 |
|---:|---|---|
| 8 | ASCII | `P2KODLC1` |
| 4 | `u32` | 형식 버전 `1` |
| 4 | `u32` | 항목 수, 1~32 |

## 항목

| 크기 | 형식 | 설명 |
|---:|---|---|
| 2 | `u16` | UTF-8 파일 이름 바이트 길이 |
| 가변 | bytes | 하위 경로가 없는 파일 이름 |
| 8 | `u64` | 원본 크기 |
| 8 | `u64` | 결과 크기 |
| 32 | bytes | 원본 SHA-256 |
| 32 | bytes | 결과 SHA-256 |
| 8 | `u64` | 압축 해제 후 명령 스트림 길이 |
| 8 | `u64` | 저장된 zlib 데이터 길이 |
| 가변 | bytes | zlib으로 압축한 명령 스트림 |

항목 이름·크기·해시는 `config.json`의 `engineData.entries[]`와 정확히 같아야 합니다. 파일 끝에 선언되지 않은 바이트가 남으면 거부됩니다.

## 명령 스트림

각 결과 파일은 다음 명령을 순서대로 연결해 만듭니다.

### COPY

| 크기 | 형식 | 설명 |
|---:|---|---|
| 1 | `u8` | 명령 `0` |
| 8 | `u64` | 원본 시작 오프셋 |
| 8 | `u64` | 복사 길이 |

### ADD

| 크기 | 형식 | 설명 |
|---:|---|---|
| 1 | `u8` | 명령 `1` |
| 8 | `u64` | 추가 데이터 길이 |
| 가변 | bytes | 결과에 직접 추가할 데이터 |

명령 결과의 합은 선언된 결과 크기와 정확히 같아야 합니다. COPY 범위가 원본을 벗어나거나 알 수 없는 명령이 있으면 패치를 중단합니다. 압축은 raw DEFLATE가 아니라 zlib 래퍼가 포함된 Deflate 스트림입니다.

## 배포 경계

패키지에는 `config.json`과 직접 제작한 차이 데이터만 넣습니다. 원본 파일, 완성된 파일, 게임에서 그대로 추출한 자산은 포함하지 마세요.
